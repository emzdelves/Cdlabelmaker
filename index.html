CD Label Cropper

Crop images to a circular CD label (default 119mm with 18mm centre hole). Export PNG with transparency.

Drag to move image. Pinch to zoom on touch. Use zoom slider to fine-tune. When ready, press Download.

Notes

  • Default DPI is 300 (good for printing). Increase DPI if your print shop requires higher resolution.
  • Output filename will be cd-label.png. The PNG has transparent regions outside the outer circle and inside the centre hole.
  • To install as an app on Android: open this page in Chrome, open menu → Add to Home screen.
